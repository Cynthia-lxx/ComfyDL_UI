Basic8 nodes

Linear, embedding, reshape and broadcast arithmetic — the wiring blocks every network is built from.

Add
BasicAdd
Element-wise addition of two tensors (broadcasting); use it for residual / skip connections.
Broadcast
BasicBroadcast
Broadcast (view) a tensor to a comma separated shape string, e.g. "2,3".
Concat
BasicConcat
Concatenate two tensors along one dimension (torch.cat).
Embedding
BasicEmbedding
Lookup table: gathers rows of weight by integer index; the table is wired in as a tensor.
Flatten
BasicFlatten
Flatten dimensions start_dim..end_dim into one; defaults flatten (N, C, H, W) to (N, C*H*W).
Linear
BasicLinear
Fully-connected layer: tensor @ weight.T (+ bias); weight/bias are wired in as tensors.
Multiply
BasicMultiply
Element-wise multiplication of two tensors (broadcasting); useful for gating or scaling.
Reshape
BasicReshape
Reshape to a comma separated shape string, e.g. "1,-1"; -1 infers one dimension.

Activation14 nodes

Element-wise nonlinearities: one tensor in, one tensor out.

ELU
ActivationELU
Exponential linear unit: x if x > 0 else alpha * (exp(x) - 1).
GELU
ActivationGELU
Gaussian error linear unit; choose the exact or tanh approximation.
Hard Swish
ActivationHardSwish
Piecewise-linear SiLU approximation: x * relu6(x + 3) / 6.
Identity
ActivationIdentity
Pass-through activation; returns the input tensor unchanged.
Leaky ReLU
ActivationLeakyReLU
ReLU variant that keeps a small slope (negative_slope) for x < 0.
Mish
ActivationMish
Mish activation: x * tanh(softplus(x)).
ReLU
ActivationReLU
Element-wise rectified linear unit: max(0, x).
ReLU6
ActivationReLU6
ReLU clamped to [0, 6]: min(max(0, x), 6).
SELU
ActivationSELU
Self-normalizing ELU with the standard scale/alpha constants.
Sigmoid
ActivationSigmoid
Element-wise sigmoid: 1 / (1 + exp(-x)); output range (0, 1).
SiLU
ActivationSiLU
Sigmoid linear unit (swish): x * sigmoid(x).
Softmax
ActivationSoftmax
Normalize values along one dimension so that they sum to 1.
Softplus
ActivationSoftplus
Smooth ReLU approximation: log(1 + exp(x)) (beta=1, threshold=20).
Tanh
ActivationTanh
Element-wise hyperbolic tangent; output range (-1, 1).

Convolution5 nodes

Learned spatial filters: conv, transpose conv, upsample and pixel (un)shuffle for feature maps.

Conv
ConvolutionConv
Convolution over 1/2/3 spatial dims with grouped/dilated kernels and zeros/reflect/replicate/circular padding; weight and bias are wired in.
ConvTranspose
ConvolutionConvTranspose
Transposed convolution (upsampling) over 1/2/3 spatial dims with stride/padding/output_padding/groups; weight and bias are wired in.
Pixel Shuffle
ConvolutionPixelShuffle
Reshuffle (N, C*r^2, H, W) into (N, C, H*r, W*r): channels become sub-pixels, the parameter-free half of sub-pixel convolution.
Pixel Unshuffle
ConvolutionPixelUnshuffle
Reshuffle (N, C, H*r, W*r) into (N, C*r^2, H, W): the exact inverse of Pixel Shuffle.
Upsample
ConvolutionUpsample
Interpolation upsampling over 1/2/3 spatial dims (nearest/linear/bilinear/bicubic/trilinear, scale_factor, align_corners); parameter-free.

Pooling2 nodes

Sliding-window and adaptive down-sampling over 1/2/3 spatial dims.

Adaptive Pool
PoolingAdaptive
Adaptive pooling (avg/max) to an exact output_size over 1/2/3 spatial dims; output_size=1 is global pooling.
Pool
PoolingSliding
Sliding window pooling (max/avg) over 1/2/3 spatial dims - MaxPool{1,2,3}d and AvgPool{1,2,3}d in one node.

Normalization7 nodes

Batch / instance / layer / group / RMS / weight / spectral — every standard re-scaling scheme.

BatchNorm
NormalizationBatchNorm
Batch normalization over the channel dimension of (N, C, ...); one node covers the 1d/2d/3d flavours.
GroupNorm
NormalizationGroupNorm
Normalization over groups of channels; num_groups=1 normalizes over all channels.
InstanceNorm
NormalizationInstanceNorm
Per-sample, per-channel normalization over the spatial dimensions of (N, C, ...).
LayerNorm
NormalizationLayerNorm
Layer normalization over the trailing dimensions, e.g. "last" or "8,16".
RMSNorm
NormalizationRMSNorm
Root-mean-square normalization over the trailing dimensions, e.g. LLaMA style.
SpectralNorm
NormalizationSpectralNorm
Divide a weight by an estimate of its largest singular value (deterministic power iteration).
WeightNorm
NormalizationWeightNorm
Re-parameterize a weight as g * v / ||v||, i.e. separate its direction from its scale.

Regularization1 nodes

Dropout and friends: training-time noise that keeps networks honest.

Dropout
RegularizationDropout
Zero each element with probability p and rescale the rest by 1/(1-p); eval mode passes the input through.

Recurrent3 nodes

RNN / LSTM / GRU cells for sequence state.

GRU
RecurrentGRU
The gated recurrent unit with its reset / update gates, single layer and batch-first; weights and the initial state are wired in as tensors.
LSTM
RecurrentLSTM
The LSTM cell with its input / forget / candidate / output gates, single layer and batch-first; weights and both initial states are wired in as tensors.
RNN
RecurrentRNN
The vanilla tanh recurrent cell, single layer and batch-first: weights, biases and the initial state are wired in as tensors.

Attention8 nodes

Multi-head, self and cross attention, transformer blocks, and the masks / positional encoding that feed them.

Causal Mask
AttentionCausalMask
Lower-triangular boolean attention mask (True = attend): position i may see positions <= i, the decoder / language-model mask.
Cross-Attention
AttentionCross
Cross-attention: queries from tensor, keys/values from context; the encoder-decoder / multimodal form.
Multi-Head Attention
AttentionMultihead
Multi-head attention over wired q/k/v tensors: projections, scaled dot-product, optional mask, softmax and output projection.
Padding Mask
AttentionPaddingMask
Boolean attention mask from per-sample sequence lengths: True = valid token, False = padding tail; broadcasts over heads and queries.
Positional Encoding
AttentionPositionalEncoding
Fixed sinusoidal position table (length, width), optionally added onto a wired sequence: order information without learnable parameters.
Self-Attention
AttentionSelf
Self-attention on one tensor: q=k=v=the wired input, projections from the wired weight set.
Transformer Decoder Block
TransformerDecoderBlock
Post-LN Transformer decoder block: Self-Attn -> Add -> LN -> Cross-Attn (k/v from context) -> Add -> LN -> FFN -> Add -> LN, all weights wired in.
Transformer Encoder Block
TransformerEncoderBlock
Post-LN Transformer encoder block: LayerNorm -> MHA -> Add -> LayerNorm -> FFN -> Add, all weights wired in.

Text4 nodes

Vocabulary building, token encoding / decoding and the sliding-window sampling that turns text into training pairs.

Sliding Window
TextSlidingWindow
Cuts a token-index stream into (context, next token) sample pairs: the next-token dataset of a language model.
Text Decode
TextDecode
Decodes token indices (1-D stream or 2-D batch) back into text through a vocabulary.
Text Encode
TextEncode
Encodes text into a 1-D long tensor of token indices through a vocabulary; unknown tokens become <unk>.
Vocab Build
TextVocabBuild
Builds a deterministic token vocabulary (with <unk> at index 0) from a corpus string, at char or word level.

Training23 nodes

Learnable parameters, optimizers, schedulers, the training loop, loss / metrics / evaluation, persistence — and the whole language-model pipeline.

Evaluate
TrainingEvaluate
Evaluates a model (nn_model) or a parameter set (PARAMS) on x/y: loss, metric and predictions, without training.
Language Model Build
LanguageModelBuild
Materialises a spec chain into a seeded nn.Module language model and reports its parameter count.
Language Model Embedding
LanguageModelEmbedding
First spec link of a language model: token embedding width, vocabulary size and the optional sinusoidal position encoding.
Language Model Forward
LanguageModelForward
Runs a language model in eval mode and returns the per-position next-token logits of a batch of token-index sequences.
Language Model Generate
LanguageModelGenerate
Autoregressive continuation of a prefix: greedy or temperature-sampled next tokens, seeded locally, with optional text decode through a vocabulary.
Language Model Train
LanguageModelTrain
Trains a language model on (context, next-token) samples inside the node: forward + backward + optimizer.step per step, returning a new trained model and the loss history.
Language Model Transformer Block
LanguageModelTransformerBlock
Appends one pre-LN transformer block (causal self-attention + FFN) to a language-model spec chain; the width follows the embedding link.
Learnable Parameters
TrainingParameters
Creates a named trainable parameter: from a wired tensor, or from the shape/init widgets.
Load Language Model
LanguageModelLoad
Reads a language model from a .safetensors file written by Save Language Model (relative to the output folder, or absolute), returning model + vocabulary.
Load Parameters
TrainingLoadParameters
Reads a parameter set from a .safetensors file (relative to the output folder, or absolute).
Loss
TrainingLoss
Computes one loss (mse / l1 / smooth_l1 / cross_entropy / bce_with_logits / kl_div) between a prediction and a target.
LR Scheduler
TrainingLRScheduler
Publishes the LR scheduler settings (StepLR / cosine / exponential / one-cycle / plateau) for a trainer node.
Merge Parameters
TrainingParametersMerge
Concatenates two parameter sets; colliding names are renamed with a warning.
Metrics
TrainingMetrics
Computes one metric (mae / rmse / accuracy / top_3 / top_5 / perplexity) between a prediction and a target.
Optimizer
TrainingOptimizer
Publishes the optimizer settings (type, lr, betas, eps, weight decay) for a Training Loop node.
Parameters to Tensor
TrainingParametersExtract
Pulls one named entry out of a parameter set as a tensor, e.g. layer0.weight for a Linear node.
Parameters to Text
TrainingParametersToText
Encodes a parameter set into copyable text (CDLPARAMS1:<base64>) that survives inside a workflow file.
Save Language Model
LanguageModelSave
Saves a language model as a .safetensors file in the output folder (spec chain and vocabulary in the metadata), and passes the model through.
Save Parameters
TrainingSaveParameters
Saves a parameter set as a .safetensors file in the output folder, and passes it through.
Text to Parameters
TrainingTextToParameters
Decodes text produced by 'Parameters to Text' back into a trainable parameter set.
Training Loop
TrainingLoop
Trains a small MLP on x/y inside the node (forward + backward + optimizer.step) and returns the trained parameters, loss history and predictions.
Training Mode
TrainingMode
Publishes train/eval to every node whose mode slot is linked to it; flip it to switch a graph between training and inference.
Training Run Stats
TrainingRunStats
Editable running_mean / running_var for eval mode; wire the outputs into the running stat slots of BatchNorm / InstanceNorm.
